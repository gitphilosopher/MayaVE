# Maya – Audio Operating System
# Install: pip install -r config/requirements.txt
#
# ── PyTorch & CUDA Acceleration (Windows) ────────────────────────────────────
# IMPORTANT: On Windows, standard `pip install torch` resolves to CPU-only wheels.
# For CUDA GPU acceleration (required for GPU Kokoro neural TTS and fast Silero VAD),
# install PyTorch with the explicit CUDA wheel index matching your CUDA version:
#
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu126
#
# Alternatively, install all requirements with the CUDA wheel index via --extra-index-url:
#   pip install --extra-index-url https://download.pytorch.org/whl/cu126 -r config/requirements.txt
#
# Supported PyTorch CUDA wheel repository URLs:
#   CUDA 12.6: https://download.pytorch.org/whl/cu126
#   CUDA 12.4: https://download.pytorch.org/whl/cu124
#   CUDA 12.1: https://download.pytorch.org/whl/cu121
#   CUDA 11.8: https://download.pytorch.org/whl/cu118
#
# ── Model Prefetch & Offline Inference ────────────────────────────────────────
# After package installation, prefetch BGE and Kokoro weights before offline execution:
#   python scripts/fetch_models.py
# (Or verify offline readiness with `python scripts/fetch_models.py --verify-only`)
